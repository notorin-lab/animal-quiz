🐾 どうぶつ なまえあてクイズ

ひらがなで動物の名前をあてる、シンプルで楽しい知育クイズゲームです。
スマホでもパソコンでも、ブラウザだけで簡単に遊ぶことができます。

🎮 あそびかた

表示される「ヒント」を読みます。

動物の名前を「ひらがな」で入力欄に打ち込みます。

「こたえる！」ボタンを押すか、エンターキーを押します。

全10問に挑戦して、ハイスコアを目指しましょう！

✨ 特徴

レスポンシブデザイン: スマホ、タブレット、PCのどれでも綺麗に表示されます。

ライフシステム: 3回間違えるとゲームオーバーになるドキドキ感。

ランダム出題: たくさんの動物データから毎回ランダムに10問選ばれます。

可愛いデザイン: お子様でも親しみやすいフォントと色使いにしています。
